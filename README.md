# Craft Shop Data Analysis

## Objective
Analyse sales of a small online craft shop to find which city, product and month sell the most.

## Data
18 orders (Jul to Sep) with OrderID, Month, City, Product, Quantity, UnitPrice and Total.
The data was created by me for practice. It has no customer names or phone numbers.

## Key Numbers
- Total orders: 18
- Total units sold: 46
- Total sales: Rs 164,600
- Average order value: Rs 9,144

## Findings
- Top city: Lahore (Rs 55,300)
- Lowest city: Islamabad (Rs 18,200)
- Top product: Embroidered Shawl (Rs 50,800)
- Top month: Aug (Rs 79,400)
